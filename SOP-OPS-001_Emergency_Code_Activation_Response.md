# HOSPITAL OPERATIONAL POLICY

**Document ID:** SOP-OPS-001  
**Title:** Emergency Code Activation and Response Protocols  
**Domain:** Hospital Operations  

---

## Section 1: Purpose & Scope

### Clause 1.1: Objective
This Standard Operating Procedure (SOP) defines standardized activation channels, team response roles, and immediate execution workflows for hospital-wide emergency codes to safeguard patients, visitors, and staff during acute clinical or facility emergencies.

### Clause 1.2: Applicability
This policy applies to all clinical nursing staff, attending physicians, security personnel, facility engineers, emergency department staff, and central switchboard operators across all inpatient wards, outpatient clinics, and administrative buildings.

---

## Section 2: Roles and Responsibilities

### Clause 2.1: Primary Responsible Role
The **Emergency Operations Center (EOC) / Telecommunications Operator** is responsible for receiving emergency call notifications, broadcasting code announcements overhead, and dispatching designated response teams within designated response timeframes.

### Clause 2.2: Clinical Response Lead
The **Rapid Response Team (RRT) Lead / Code Blue Captain** is responsible for assuming command of clinical resuscitations upon arrival at the emergency scene.

---

## Section 3: Standard Emergency Code Classifications

### Clause 3.1: Code Classifications and Triggers
1. **Code Blue:** Cardiac or respiratory arrest involving an adult or pediatric patient.
2. **Code Red:** Fire, smoke discovery, or active thermal alarm activation.
3. **Code Pink:** Infant or pediatric abduction / missing child alert.
4. **Code Black:** Bomb threat or suspicious package discovery.
5. **Code Grey:** Aggressive, violent, or combative individual requiring immediate intervention.
6. **Code Silver:** Active shooter or weapon-bearing hostile individual.

---

## Section 4: Code Activation and Resuscitation Response Workflow

### Clause 4.1: Code Blue Activation Sequence
When a clinician discovers a patient in cardiac or respiratory arrest, staff must execute the following sequential workflow:
1. Verify unresponsiveness and absence of pulse/breathing.
2. Dial the internal emergency extension (**ext. 5555**) or push the wall-mounted Code Blue alarm button.
3. State to the operator: "Code Blue, [Building Name], [Floor Number], [Room/Location]".
4. Initiate immediate chest compressions and basic life support (BLS) steps.
5. Obtain the nearest Automated External Defibrillator (AED) / Crash Cart.
6. Switchboard operator broadcasts "Code Blue, Room [X]" overhead **three times** and automatically pages the Rapid Response Team.
7. Code Blue Team arrives on site within **3 minutes**, and the Code Captain assumes ALS leadership.

### Clause 4.2: Code Pink Security Lockdown Sequence
Upon notification of a suspected infant abduction:
1. Call ext. 5555 to declare "Code Pink" with patient description and last known location.
2. Switchboard broadcasts "Code Pink" overhead across all hospital sectors.
3. Security personnel immediately lock down all facility perimeter doors, stairwells, and elevator banks.
4. Staff check all hallways, exit corridors, and restrooms within their assigned departments for unauthorized carry bags or individuals matching the alert description.

---

## Section 5: De-activation and Debriefing Protocol

### Clause 5.1: Code Clearance Announcement
Only the designated Incident Commander, Code Captain, or Security Lead may authorize the Telecommunications Operator to broadcast an "All Clear" announcement overhead.

### Clause 5.2: Post-Event Incident Documentation
Following any emergency code activation, the initiating nurse and response team lead must complete the online Emergency Code Evaluation Form in the EHR within **12 hours** to support continuous quality improvement.
